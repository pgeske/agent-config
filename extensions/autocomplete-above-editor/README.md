# Autocomplete Above Editor

Keeps Pi's input box anchored in fullscreen mode by rendering the native autocomplete menu above the editor instead of below it.

Pi currently includes autocomplete rows in the editor's height. In fullscreen mode, placing those rows below the input causes the whole editor and footer to jump upward while slash-command suggestions are visible. Reordering the same native rows keeps filtering, selection, and keyboard behavior unchanged while allowing the menu to expand into transcript space.

Run `/reload` after installation.
