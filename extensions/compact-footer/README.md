# Compact footer

A quiet, single-line Pi footer with only the session details that matter:

```text
  gpt-5.6-sol  ·  thinking max  ·  session main-branch-153               context 7.5%
```

The model is shortened to the final part of its ID, context pressure changes color at 70% and 90%, and the session side truncates before the right-aligned context value. The line always keeps two columns of breathing room at normal terminal widths.

Run `/reload` after installing or changing the extension.
